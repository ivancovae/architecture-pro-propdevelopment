## Таблица ролей и полномочий:
| Роль                       | Права роли                                                                                                             | Группы пользователей                           |
|----------------------------|------------------------------------------------------------------------------------------------------------------------|------------------------------------------------|
| cluster-admin              | Полные права в кластере (создание/изменение/удаление всех основных ресурсов, включая secrets, ingresses)               | Инженеры по эксплуатации (Ops), DevOps-инженеры |
| view-only                  | Чтение большинства ресурсов (pods, services, configmaps, secrets, deployments, jobs, namespaces): get, list, watch     | Бизнес-аналитики, владельцы продукта           |
| developer                  | Создание/изменение приложений без доступа к секретам (deployments, services, configmaps, ingress), чтение logs, events | Разработчики                                   |
| compliance-auditor         | Чтение всех ресурсов кластера (включая роли/привязки), secrets                                                         | Специалист по ИБ                               |

Создание пользователей описано в [users.yaml](users.yaml)
```shell
kubectl apply -f users.yaml
```

Создание ролей [roles.yaml](roles.yaml)
```shell
kubectl apply -f roles.yaml
```

Привязка ролей к пользователям [rolebindings.yaml](rolebindings.yaml)
```shell
kubectl apply -f rolebindings.yaml
```
