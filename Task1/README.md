## Задание 1. Разработка проверочного листа по безопасности данных

# Проанализируйте диаграмму и описание системы PropDevelopment.

Персональные данные (ПДн) — это любая информация, относящаяся прямо или косвенно к определённому или определяемому физическому лицу.

* Публичные данные
1 - Витрина квартир (онлайн без ПДн, рекламная информация)
Некачественные данные — значительный
Ошибки в параметрах может ввести клиентов в заблуждение

2 - Информация на сайте (новости, PR, проекты, контакты о компании)
Искажение — критический
Подмена информации ухучшает доверие и влияет на продажи

* Внутренние данные
1 - Регламенты, инструкции, переписка(корпоративная), уставы
Утечка — значительный
Снижение конкурентного преимущества

2 - Данные эксплуатации ЖК (без ПДн)
Потеря — значительный
Срывы работ и ухудшение сервиса 

* Конфиденциальные данные
1 - ПДн клиентов, договоры, бронирования
Утечка — критический
Штрафы, иски и репутационный ущерб

2 - История платежей/сделок
Обесценивание — значительный
Устаревание снижает точность и CX(Customer Experience, весь путь взаимодействия клиента с брендом)

* Секретные данные
1 - Доступы/ключи к ИС (логины, пароли, API, секреты)
Потеря — критический
Остановка систем и простои, страдает доступность сервисов

2 - Финансовая отчётность, планы, структура орг. структуры
Утечка — критический
Может привести к убыткам/манипуляциям, нарушение работы организации
